# 保育園シフト作成 PoC

保育園の月間シフトを、**休みの自動配置 → 人による修正 → 当番の自動配置**の2段階で作るための最小プロトタイプです。

## 現在の仕様

### 標準シフト

| 開始 | 必要人数 |
|---|---:|
| 06:45 | 2 |
| 07:30 | 1 |
| 08:00 | 2 |
| 08:30 | 3 |
| 09:00 | 2 |
| 09:45 | 5 |
| 11:30 | 2 |

正規保育士の標準勤務は実働8時間＋休憩45分を前提とします。

### 強い条件

- 日曜・祝日は休園
- 06:45 は正規有資格者2名
- 11:30 は正規有資格者2名
- 08:30 時点で最低8名
- 06:45 / 11:30 は各職員に偏りすぎないように割り当て、初期値では各3回まで
- 正規保育士は月の共通休日日数を設定
- 非正規・派遣等は正規の月休日日数条件から外し、「週何日休み」「固定休曜日」で扱う
- 希望休はできるだけ優先する
- 非正規等は個別の固定勤務時間（例 09:00-16:00）を登録可能
- 職員ごとに勤務可能シフトを制限可能

## 使い方

1. `index.html` をブラウザで開く
2. 対象月、正規保育士の月休日日数、祝日を設定
3. 職員マスタを入力
4. **休みを自動配置**を押す
5. 月間表のセルをクリックして休みを手修正
6. **当番を自動配置**を押す
7. 不足警告を確認し、必要なら条件や休みを調整
8. CSV出力

入力内容はブラウザの `localStorage` に保存されます。

## 現段階の制限

これは最適化ソルバーではなく、まず実運用を触って仕様を固めるためのヒューリスティック版です。

未実装・今後詰めるもの：

- 日本の祝日の自動取得
- 労働時間・連続勤務・変形労働時間制など就業規則に応じた厳密な労務チェック
- 06:45 / 11:30 の「合計上限」か「各上限」かの最終仕様
- 職員同士の組み合わせ条件
- 曜日ごとの必要人数差
- 土曜日専用シフト
- 第2段階の勤務セルを直接手修正するUI
- 数理最適化による公平性の改善

## 方針

まずこのPoCで実際の職員条件を入れて、どこで破綻するか・どの手修正が多いかを確認し、その結果から本番用の制約モデルへ移行します。
