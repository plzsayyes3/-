基本設定

日曜は自動で休園。祝日は最小版では日付を手入力します。6:45 / 11:30 は「各シフト3回まで」を初期値にしています。

勤務可能シフト
固定休曜日は「月,木」のように入力。希望休は「3,12,25」。固定勤務は「09:00-16:00」。正規保育士は固定勤務を空欄にし、勤務可能シフトを必要に応じて制限します。

1. 休みを作る

自動配置後、セルをクリックすると「勤務 / 休み」を手で切り替えられます。日曜・祝日は固定です。

2. 当番を入れる

必要枠：6:45×2 / 7:30×1 / 8:00×2 / 8:30×3 / 9:00×2 / 9:45×5 / 11:30×2。6:45・11:30は正規保育士2名を必須とします。
